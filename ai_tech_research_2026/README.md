# 近半年 AI 及前沿技术调研

创建日期：2026年10月6日

## 任务目标

调查最近半年（2026年4月到10月初）在 AI 以及其他前沿领域出现的新技术和新研究，判断哪些可以用在产品上，并给出具体的产品机会。

## 调查范围

**AI（重点）**
* 基础模型和推理能力
* Agent 与工具调用
* 多模态（语音、图像、视频生成）
* 端侧小模型
* 世界模型和具身智能（机器人）
* AI for Science
* AI 基础设施（推理成本、芯片）

**其他前沿领域（默认清单，可调整）**
* 生物医疗：基因编辑、AI 制药、健康可穿戴
* 电池和新能源材料
* 半导体
* XR 和脑机接口
* 量子计算
* 航天和低空经济

## 调查方法

1. **广泛扫描**：从学术（arXiv、顶会、Nature 和 Science）、产业（各大公司和实验室的发布）、开源社区（GitHub、Hugging Face）、市场信号（融资、YC、Product Hunt、Hacker News）四类来源，整理出约 50 项候选技术的长名单
2. **核实和筛选**：每项技术都找到一手来源并标注日期，区分"已经能用"和"只有演示或宣传"，剔除炒作
3. **统一打分**：成熟度、可获得性、成本、产品化难度、窗口期、风险
4. **对应到产品**：拿高分技术去推产品方向，写清目标用户、痛点、为什么现在能做、MVP 形态、竞品和实现路径

## 待确认事项

1. 目标产品或行业（还是不设限地找机会）
2. 团队能力：调用 API 做应用，还是能训练模型或做硬件
3. 目标市场：国内还是海外
4. "其他领域"清单是否需要调整
5. 是否在列出长名单后先停下来挑方向

## 限制说明

* 只能查公开网页，付费数据库和付费墙后的内容无法获取
* 找不到一手来源的信息会标注为"未证实"
* 评分基于公开信息，不能替代真实的用户调研和技术验证
